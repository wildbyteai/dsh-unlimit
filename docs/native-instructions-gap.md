# 原生工作区指令的剩余差距

对应 `RULE-BASELINE`，目标版本 `0.2.1-rc.2`。当前已实现按会话、按步骤处理原生基线与刷新消息，并通过官方 producer、AgentLoop 和物理 JSONL 隔离验收。完整合同见 [native-instructions-contract.md](native-instructions-contract.md)，本页保留最初调查依据及尚未闭合的边界。全文预览或系统提示词替换不能代替原生来源控制。

最初静态调查取得公开 npm 的 `@deepseek-ai/dsh-agent-instructions@0.2.1-rc.2`，归档完整性与桌面发行库存分别核对通过。干净入口 SHA-256 为 `4011f6e4c08228601bd4348ac78e322913142264f6e491ffdf9dcfda97393988`；同时核对 14 份库存匹配的官方接口及消费端文件。当时未执行 producer。后续验收在临时隔离环境执行了该干净归档；真实安装、profile 和会话始终未改动。官方代码和详细本机路径不随项目分发。

| 核对的官方接口                        | 观察及影响                                                                                                                                                |
| ------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| agent-instructions Config / apply     | 字节预算、候选文件名等是实例级静态配置；没有按会话启停或来源过滤服务。apply 捕获配置和私有缓存，直接改原配置对象不会生效。                                |
| agent-instructions baseline / refresh | 使用带 `source.kind:agent-instructions` 的 `user/message` 事件；基线既看本轮输入，也看已经接纳的 session surface。原生指令不在 systemPrompt sections 中。 |
| AgentLoop / Session                   | 请求由接纳后的 surface 派生；历史替换会更新 content generation 和请求 series。只过滤发送副本会造成请求与日志重建结果不一致。                              |
| Session replacement                   | 可以追加明确来源的替换事件并保留原始日志，但这属于会话写入。恢复必须尊重后续替换与压缩的所有权；遮掉基线还可能触发 producer 下一轮再次生成。              |
| Session message projection            | 返回值合同是模型消息而非来源删除；已经用于历史的投影定义卸载后可能阻止派生，不能视为可随时撤销的筛除器。                                                  |
| Cordis / Loader noSave                | 重挂唯一官方条目并设 `maxBytes:0` 可成为停止未来注入的候选，但它是全局实例配置，不处理已有历史；重挂也会重建缓存和刷新生命周期。                          |

实现没有采用全局零预算或 Session.append 包装。一个共享条目的单值不能同时满足不同会话的 always 与 strict，fallback 还取决于当前模型规则和正文；逐请求重挂会产生跨会话竞争。新增消息在 pre-step 下游返回后按准确来源筛选，reject 原样返回；历史在真实 step/start 后的 agent/request 内追加内建空 developer 替换事件，原始日志保留。

隔离验收已经证明已有/新增来源筛选、模型规则优先与会话隔离、完整请求从物理日志重建、后续替换所有权、拒绝/取消、在途撤销和正常代理关闭恢复。不注册卸载后仍需依赖的自定义 projection。producer 仍可能重新发现文件，但不会因筛选而增加模型循环。

剩余边界：

- 当前真实安装的 producer 入口摘要不符，原生能力不会启用；临时干净归档通过不代表实际安装已恢复。
- 不自动遍历或打开未加载的持久会话。异常退出、恢复写入失败及未加载历史的完整处理仍未验收；已加载会话可通过明确还原动作重试，失败状态不标为恢复成功。
- `fallback` 沿用当前独立实现的条件：所选模型规则和保存正文都为空白才保留。与旧项目的描述差异仍在功能对照中，没有将该解释冒充已经确认的 1:1 语义。
- 尚未安装本插件，也未进行真实桌面嵌入、重启或升级验收。
