# 原生工作区指令的剩余差距

对应 `RULE-BASELINE`，目标版本 `0.2.1-rc.2`。当前的 strict / fallback / always 只处理本项目主动选择的规则文件，尚未控制宿主已经接纳的原生工作区指令。全文预览或系统提示词替换不能代替这一能力。

本次取得公开 npm 的 `@deepseek-ai/dsh-agent-instructions@0.2.1-rc.2`，归档完整性与桌面发行库存分别核对通过。干净入口 SHA-256 为 `4011f6e4c08228601bd4348ac78e322913142264f6e491ffdf9dcfda97393988`；同时核对 14 份库存匹配的官方接口及消费端文件。仅做静态读取，没有执行此 producer、修改真实安装或追加会话事件。官方代码和详细本机路径不随项目分发。

| 核对的官方接口                        | 观察及影响                                                                                                                                                |
| ------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| agent-instructions Config / apply     | 字节预算、候选文件名等是实例级静态配置；没有按会话启停或来源过滤服务。apply 捕获配置和私有缓存，直接改原配置对象不会生效。                                |
| agent-instructions baseline / refresh | 使用带 `source.kind:agent-instructions` 的 `user/message` 事件；基线既看本轮输入，也看已经接纳的 session surface。原生指令不在 systemPrompt sections 中。 |
| AgentLoop / Session                   | 请求由接纳后的 surface 派生；历史替换会更新 content generation 和请求 series。只过滤发送副本会造成请求与日志重建结果不一致。                              |
| Session replacement                   | 可以追加明确来源的替换事件并保留原始日志，但这属于会话写入。恢复必须尊重后续替换与压缩的所有权；遮掉基线还可能触发 producer 下一轮再次生成。              |
| Session message projection            | 返回值合同是模型消息而非来源删除；已经用于历史的投影定义卸载后可能阻止派生，不能视为可随时撤销的筛除器。                                                  |
| Cordis / Loader noSave                | 重挂唯一官方条目并设 `maxBytes:0` 可成为停止未来注入的候选，但它是全局实例配置，不处理已有历史；重挂也会重建缓存和刷新生命周期。                          |

因此，本次没有实施全局零预算或 Session.append 包装。一个共享条目的单值不能同时满足不同会话的 always 与 strict，fallback 还取决于当前模型规则和正文；逐请求重挂会产生跨会话竞争。仅拦截 pre-step 的新消息也不能移除已有历史，更不能吞掉宿主原有的 reject 决定。

后续完成这项能力仍需证明：按会话处理已有和新增的明确来源事件，实际请求可以从日志完整重建，撤销只恢复本项目仍拥有的状态，且基线刷新和在途步骤不会反复注入或跨会话污染。目前这些是剩余验收条件，不是已通过的实现。
