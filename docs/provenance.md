## 自动检查能证明什么

- 语法检查证明被检查 JavaScript 文件可解析，不证明功能可用。
- 来源相关脚本只报告实际实施的文件、命名或分层检查。品牌词、扩展名、摘要一致都不能证明原创性、没有片段复制或法律上的独立作品。
- `tests/parity-baseline.test.mjs` 对照 `0bc13d2` 保存的验收数据，保护 117 项前五列；状态列按新执行证据更新。
- `npm run pack:local` 对实际 npm 发布文件清单应用允许列表和排除规则；开发目录扫描不代替发布包检查。
- 历史整文件摘要比较只说明当时没有发现整文件字节相同项，不覆盖片段或改写后的相似性。原记录仍在 [验证记录](verification.md)。

## IPv6 短表达候选的后续处理

后续重写移除了上述国家查询和 NAT64 中的两段局部解析，改由 [IP 字节解析模块](ip-bytes-design.md) 提供网络序字节。模块编写子任务只接收输入输出合同、读取项目指导与元数据，另外阅读 RFC 4291 §2.2 和 Node 官方 API 文档；没有读取两处现有实现、原参照代码、既有 IP 测试或相似性审计代码。它采用逐字段写入字节、两端对齐零填充的实现；消费者仍自行处理映射地址的 IPv4 查询语义及显示规范化。

主任务阅读现有消费者并完成接入，保留原始验收。限定模块的输入资料和新实现可追溯，不把它扩展为整个项目的净室声明，也不倒推此前短表达已经构成复制。新的测试与独立字节对照见 [验证记录](verification.md#ip-解析模块重写与消费者复验2026-10-21)；历史审计记录仍绑定当时的提交，不删除或重写。
