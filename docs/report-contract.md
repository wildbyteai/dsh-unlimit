# 工作区报告

`report.build({ workspaceId })` 保持返回 `{ markdown, stats }`。`WorkspaceStore.report()` 只读取指定工作区的工作区信息、资产、发现、12 类证据记录、资产关系和本地观察事件，再由 `src/core/report.js` 生成 Markdown。未知工作区继续拒绝；不读取真实 profile、引用文件、会话正文或其他工作区，不调用网络、工具、登录或探测，不更改记录、时间、计分或验证状态。相同记录生成相同结果，不额外写入“报告生成”事件。

## 内容与来源

- 工作区：ID、名称、授权范围、授权说明、创建和更新时间。授权说明只是登记声明，不构成实际目标授权。
- 资产与服务：名称和别名、地址、类型、域名、端口、协议、服务产品与版本、指纹、来源、范围、分段、状态、优先级、标签、说明及首次/最后观察时间。服务保留稳定 ID；名称与 ID 同时展示关联，未知服务不被推断为关闭。
- 测试与评估：展示资产当前保存的全部字段，包含执行语义、登记时间、结果、说明、证据与来源。旧记录仍在观察事件中展示；统计仅计最新记录的存在数量，不把多次测试算作多个资产。
- 发现：标题、ID、严重性、登记状态、关联资产、创建和更新时间，以及完整的文本、对象或数组证据。缺证据明确标记未提供；`confirmed` 等状态不提升为报告已验证。
- 权限、阶段、链路和其他记录：按已有记录类型分别展示全部登记字段。覆盖访问目标、级别、方式和说明；阶段名称、进度与状态；链路起止、方法、证据和关联资产；WebShell、隧道、HTTP、截图、文件和会话引用等。自由 JSON 以缩进列表呈现，已知字段使用中文标签，其余保留字段名，不增加新的存储 schema。
- 关联与观察历史：资产关系明确方向、名称、ID和关系声明；历史事件保留事件类型、数据、观察/创建/更新时间与来源。服务、资产、发现、阶段和计分点引用只从当前工作区解析；无法解析时标记“当前工作区未找到；未验证”。不沿引用读取其他工作区。

每类空记录、缺省来源、缺少测试或评估都有明确未知/未验证提示。记录者的 `verified`、`complete`、`confirmed` 只是声明；报告统一注明未独立验证。文件路径、摘要、URL 和会话 ID 不等于文件存在、摘要有效、远程可达或实际执行证据。报告不根据空记录推断没有风险、没有服务或阶段完成。

## 脱敏

沿用 [凭据合同](credentials-contract.md)：凭据 `data` 整体隐藏，包括可读元数据、说明、来源、关联与角色声明；只展示 ID、时间、秘密存在状态和隐藏遗留字段数。不展示凭据秘密、遗留字段名或原值，不因报表需要增加原始凭据读取接口。

其他记录、标题、来源和嵌套证据统一隐藏秘密字段值，包括口令、secret、token、cookie、authorization、私钥、API key 等；文本中的 Bearer/Basic 内容、HTTP Cookie/Authorization 行、HTTP(S) URL 用户信息、明确秘密查询参数、秘密赋值和 PEM 私钥块也被隐藏。阶段统计中的自由阶段声明同样脱敏。所有文本均转义 Markdown，避免输入注入标题、图片或 HTML。

这种处理不能识别未标明性质的任意字符串是否为秘密；普通非秘密字段仍不适合存放裸口令。报告仍是工作区资料，来源和业务描述可能保密，脱敏不构成对外公开授权。

## 统计兼容

保留原字段与语义：`assets`、`services`、`findings`、`records`、`severities`、`scorePoints`、`scoreHits`、`scoreUniqueHits`、`scoreByStage`、`scoreTotal`、`scoreEarned`。

得分按“计分点 ID＋资产 ID（可未指定）＋协议/端口或资产级”去重。`serviceId` 和相同 `port/protocol` 是同一端点；重复证据全部保留，`awarded:false` 仅留证。采用计分点的 `points`，不采用命中自行登记的分值。阶段采用计分点 `stageId`、再采用其自由 `stage` 声明、否则 `unassigned`；命中中的阶段声明不更改归属。`scoreTotal` 是计分点基准总和，不是可得总分上限。缺失有效计分点和非法阶段仍报错，不静默计零。

新增统计：`recordsByKind` 包含全部12类记录数量（包括0）；`assessments`、`tests` 是有当前评估/测试记录的资产数；`links`、`events` 是当前工作区的关系与观察事件数。未增加“已验证总数”或扫描完成率。

## 本地验证与限制

`node --test tests/report.test.mjs tests/store.test.mjs tests/credentials.test.mjs` 使用原创合成 SQLite，覆盖空库、完整已有字段、全部12类记录、关联名称和原 ID、来源与历史、计分去重/阶段/仅留证、Markdown 转义、跨工作区隔离，以及正文/统计秘密不泄漏。报告测试在 `PRAGMA query_only = ON` 下构建，比较所有 entries 和 metadata 前后逐行一致，并验证相同数据重复构建结果一致。

这些验证只证明本地已有数据的报告合同。未复制其他插件代码或内容；未与其他插件逐字输出比较，不宣称旧报告原文或桌面 0.2.1-rc.2 的 1:1 验收。报告下载页面、真实桌面嵌入与实机操作仍须单独验证；未安装或更改真实 profile。
