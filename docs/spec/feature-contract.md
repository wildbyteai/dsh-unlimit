# 桌面实现范围说明

本文件是接续开发的索引，不是替代规格。完整功能范围与最低验收以 [117 项行为对照](../parity.md) 为准，接口和数据约定以 [contract.md](../contract.md) 为准。二者有冲突时应查明并记录，不能通过另写一份简化规格消除差距。

## 已确认目标

- 项目名 `dsh-unlimit`，公开源码，独立实现既定桌面能力，界面重新设计。
- 当前适配目标为 DeepSeek Harness desktop `0.2.1-rc.2`，验收设备为 macOS arm64；其他平台的条目保留真实未验状态。
- 不复制参照插件的代码、提示词、技能或素材，不使用原作者服务和更新渠道；准确保留 [开发来源](../provenance.md)。
- 只通过已适配的官方接口提供能力。缺接口时报告缺口，不修改宿主二进制，也不把部分注册或失败的执行报告为全部生效。

## 必须继续保留的功能范围

行为对照包含运行控制、提示词与规则、技能导入、服务器名单和范围执行、授权入场、资产与凭据、环境检查、编排与角色、评分与报告、会话历史和恢复、桌面生命周期及兼容性。演练台不能缩减成仅“授权前置”和“导出报告”；各项用户可观察结果仍须逐条实现与验证。

权限、工具集合和计划模式采用当前官方合同；不能为凑齐功能而把一种模式伪装为另一种模式。任意新增目录授权、真实进程沙箱、MCP/终端/浏览器网络出口等尚未验证或不支持的能力继续列为差距。

启用、撤销、卸载分别有实际结果和所有权范围。撤销保留用户文本、技能及无关配置；卸载按既有 [生命周期合同](../maintenance-contract.md) 执行，不新增“删除规则库”或“自动重启宿主”的要求。

## 验收与操作边界

`tests/fixtures/desktop-parity-baseline.json` 保存 `0bc13d2` 中 117 项验收的前五列。状态列可以根据测试更新；不得只因为实现不满足要求就改写前五列。更改已确认范围必须有用户授权并更新相应合同。

当前授权仅覆盖本地实现与隔离验证，暂不安装插件，不改真实 DSH profile、会话或配置。模式执行与文件交付使用原创临时文件，不能用假工具返回值代替实际执行证据。Web 独立部署和原作者渠道继续排除。
