## Hook 与原生拒绝

官方 `dsh-agent` 提供按 Agent 注册的事件和输入 API。`agent/pre-step` 可以拒绝拟进入模型的一步；`dsh-agent-loop/lib/index.js:902–926,956–963` 将该拒绝结束为整轮 `blocked`。`agent/turn-stopping` 是停止前通知，本身不制造用户发言（`1000–1007`）。

工具拒绝属于另一层：`dsh-tools/lib/index.js:3321–3362` 的 `tools/pre-execute` 和后续 guard 可以阻止单次工具执行并返回错误结果，不等于拒绝整个正常轮次。审批的用户拒绝、取消、通道不可用保持不同的非授权结果（`3535–3585`）；结果策略也不能把失败替换成成功值（`3599–3627`）。

本插件不得为了使 Hook 开关看似生效而吞掉其他所有者的拒绝、审批或取消。Stop 提示必须保留插件来源，不能包装成人工发言。历史 `hook/invoked` / `hook/result` 及 `claude-code/codex` 标签只证明审计格式存在，不能证明当前有对应执行器或配置服务。

## 第三方记忆与 MCP

原生工作区指令、MCP 服务说明、第三方插件通知及人工消息是不同来源。消息使用 user role 或包含“记忆”文案，都不足以确定其属于第三方记忆集成。

官方 `dsh-mcp-client` 是可选通用桥接，支持独立 Agent scope。其配置包含连接、超时、重连及说明字节预算，没有只关闭记忆段或通知的字段（`lib/index.js:769–800`）。`maxInstructionBytes` 最小为 1，是连接接收预算，不能用缩小预算冒充内容开关。

成功连接会贡献 `mcp:<serverName>` 说明段；完整停用会关闭连接并撤销工具和资源（`654–657,700–714,731–742,809–830`）。**停用整个 MCP 不等于仅禁用记忆内容。** 已读资源和工具结果也不会因此从历史中消失。

最终提示段只有名称、正文和插值标志，没有 owner 或插件来源；同名段还可被近 scope 覆盖（`dsh-system-prompt/lib/index.js:385–398`、`dsh-scope/lib/index.js:177–180`）。因此 `mcp:` 前缀、serverName、段名或文本匹配都不能单独作为删除依据。全局关闭 optional runtime context 也不是记忆专用策略。

## 开始适配前必须具备

- 明确公开的目标包、版本、干净入口摘要及其内容来源，能唯一定位实际注册实例；未知来源保持不支持。
- 目标提供可撤销配置接口，或本插件直接拥有内容 producer 和注册 disposer；不以替换全局方法、吞拒绝或停用无关能力代替定向控制。
- 明确每 Agent 的范围和生命周期。通用 scope 父链会继承注册并把后代事件送给祖先监听器；精确会话控制须核对实际 Agent，恢复、重建及撤销冲突需要验证。
- 用合成来源覆盖允许、拒绝、停止提示和记忆保留切换；证明人工消息、无关指令、工具结果、审计及原生审批保持原义。先完成隔离执行，再单独记录桌面验收；静态证据不能代替行为通过。

这些条件允许独立实现本插件拥有的 Hook 或记忆集成，不自动构成对现有第三方协议的 1:1 适配。
