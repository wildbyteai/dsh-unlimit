# 桌面行为对照与验收清单

本清单由旧项目本地源码的只读分析独立归纳，不包含旧源码、替换表达式、默认提示词正文、技能正文或素材。目标是桌面端可观察结果一致；补丁条数不构成功能条数。参照旧包 `package.json` 的版本为 1.1.72，README 仍标 1.1.71；旧包声明目标为 0.2.0-rc.2，不能由此宣称已适配 0.2.1。新项目当前合同的验收设备为 macOS arm64、宿主 0.2.1-rc.2。本文没有启动旧插件，没有读取用户 profile，没有执行网络探测。

当前行状态已按本地证据更新，**没有任何保留行宣称完整桌面1:1通过**。“部分”只认可所列子路径；“源码”不表示执行过；“合成”表示临时数据/假服务；“官方隔离”表示真实官方模块与假传输；“预览”是1280×820回环工作台交互。所有桌面实机路径仍未验收。证据层级、具体断言、复验命令和限制见 [verification.md](verification.md)。Windows项必须在Windows实机执行后才可通过。

类别含义：**保留**表示本次桌面功能对齐目标；**兼容**表示旧实现为历史宿主、历史数据或发行方式修复的问题，0.2.1 已原生满足时验证结果即可；**排除**表示用户明确不纳入本次实现。官方 API 缺少能力、权限被宿主拒绝或平台不匹配时，应记录不支持/待实现及原因，不能把设置已保存、请求返回成功或本地单测当作行为通过，也不能通过修改宿主二进制、规避安全控制来填补差距。

**提示词优先级存在明确语义差异：**旧README称“自写正文→所选工作区规则→默认正文”，旧实时实现却先取得通常非空的默认正文，所选规则兜底可能不可达；fallback也存在“用户正文存在”与“任意非空注入”的歧义。当前独立实现采用：模型专用规则优先于全局活动规则，随后为保存正文、所选工作区文本、原创默认正文；没有旧进程缓存回退。strict不读取选定文件，fallback仅在没有规则及保存正文时采用选定工作区文本，always追加选定工作区文本；replace保留官方工具段/工具schema与独立运行时上下文，append保留原系统段。这是当前可复验的实现语义，不能把对旧源码歧义的选择标为旧桌面1:1通过，仍需产品侧确认该差异。

## 当前实际缺口与验收边界

以下是当前工作树的范围差距，不因测试通过而消失。它们需要后续明确实现范围与验收；本轮不承诺完整1:1。

1. **运行时控制不齐。** 全局字节读取上限、重复调用限制、Hook策略、第三方记忆段策略、重试次数没有可用的已验证接口；设置保存不生效。权限扩大闭环尚未接入；默认权限/审批配置不能证明文件、终端、浏览器、交付工具及所有模式已实际遵守。指定官方会话日志插件可临时关闭，但不涵盖所有遥测、已在途请求或默认包装器的全部副作用。
2. **范围名单和授权门缺失。** ownServers目前仅存字符串数组，没有标准化、拒绝秘密/网段/通配符、精确DNS/地域判定，更未接主/子代理或网络出口执行。演练入场倒计时、阅读勾选、独立安装授权持久化及撤销重置均未实现。名单不能作为已经生效的目标许可或网络边界。
3. **回退与继续未闭环。** 合成fork/停止/归档测试可证明切点和部分失败处理，但没有实际官方SessionController fork及composer草稿桥证据；附件恢复、任务状态重写、子代理到父切点不支持。UI未发现桥时禁用回退。官方请求重试已验证当前prompt及持久日志一致，手动/自动继续、继续次数/原因分类与停止竞态仍缺；回退后重发不在协议通过范围。
4. **数据记录有边界。** 本地资产/服务/发现/链/计分/知识/报告已提供较完整数据路径，但凭据/会话/HTTP/截图/file等仍是本地记录，不是登录、Shell、隧道或连通性执行。二进制截图上传/有效性/预览、工作区实际文件树、图路径查询、本地模板目录、任意采集包格式未形成同等闭环；报告不声称覆盖旧版全部字段。秘密脱敏的现有证据主要是报告，不能扩展为所有API/UI均完成逐字段秘密治理。
5. **流程只有显式分配与本地准入。** 六份原创角色、工作区覆盖、默认3槽和显式领取/释放已实现；没有自动拆任务/启动执行者/协调回填的调度器，也不能强制所有官方子代理先领取本地槽。官方子会话请求中的角色正文、MCP聚合/任务匹配、预设注册与迁移尚未验证或实现。
6. **工具管理限定为登记与版本探测。** 只接受显式根及一层子目录，固定argv `--version`、离线缺失建议，不提供扫描、通用start/stop/output或联网安装。额外搜索路径、逐工具路径、PATH优先级、模板/秘密变量、同名工具身份判断和首次配置门均未对齐。此限制不能被“本地工具可用”掩盖，也不应擅自扩大成扫描服务。
7. **规则与技能部分合同不同。** 优先级和工作区策略按上文当前语义实现；不复刻旧缓存或外部规则文件快照。技能当前上限为ZIP12MiB、展开50MiB、SKILL正文256KiB、最多512文件；文件数与旧清单200不同。provider可列/可读不等于桌面技能命中和调用已验；官方技能全集及依赖目录未整合。
8. **生命周期仍需实际安装验收。** 卸载、插件本地安装/升级动作、重启、实际HMR/退出、双安装/profile隔离、升级保留数据和Windows启动行为仍未验或未实现。当前只明确支持0.2.1-rc.2；未知宿主版本拒绝运行注册，不能自动宣称兼容新版本。合成mount/dispose与离线包构建都不能代替桌面安装。
9. **真实请求证据限定清楚。** 四协议由官方AgentLoop/适配器/SDK组装，20次假fetch观测与持久消息一致，首轮、更新后的第二轮、进程内子会话首轮及503重试均有原生系统槽证据；仍无外部代理进程、真实模型联网、真实输出质量或回退/继续请求证据。已加载入口摘要匹配不代表整机宿主全部模块原始干净。
