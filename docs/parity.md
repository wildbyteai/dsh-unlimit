# 桌面行为对照与验收清单

本清单由旧项目本地源码的只读分析独立归纳，不包含旧源码、替换表达式、默认提示词正文、技能正文或素材。目标是桌面端可观察结果一致；补丁条数不构成功能条数。参照旧包 `package.json` 的版本为 1.1.72，README 仍标 1.1.71；旧包声明目标为 0.2.0-rc.2，不能由此宣称已适配 0.2.1。新项目当前合同的验收设备为 macOS arm64、宿主 0.2.1-rc.2。本文没有启动旧插件，没有读取用户 profile，没有执行网络探测。

当前行状态已按本地证据更新，**没有任何保留行宣称完整桌面1:1通过**。“部分”只认可所列子路径；“源码”不表示执行过；“合成”表示临时数据/假服务；“官方隔离”表示真实官方模块与假传输；“预览”是1280×820回环工作台交互。所有桌面实机路径仍未验收。证据层级、具体断言、复验命令和限制见 [verification.md](verification.md)。Windows项必须在Windows实机执行后才可通过。

类别含义：**保留**表示本次桌面功能对齐目标；**兼容**表示旧实现为历史宿主、历史数据或发行方式修复的问题，0.2.1 已原生满足时验证结果即可；**排除**表示用户明确不纳入本次实现。官方 API 缺少能力、权限被宿主拒绝或平台不匹配时，应记录不支持/待实现及原因，不能把设置已保存、请求返回成功或本地单测当作行为通过，也不能通过修改宿主二进制、规避安全控制来填补差距。

**提示词优先级存在明确语义差异：**旧README称“自写正文→所选工作区规则→默认正文”，旧实时实现却先取得通常非空的默认正文，所选规则兜底可能不可达；fallback也存在“用户正文存在”与“任意非空注入”的歧义。当前独立实现采用：模型专用规则优先于全局活动规则，随后为保存正文、所选工作区文本、原创默认正文；没有旧进程缓存回退。strict不读取选定文件，fallback仅在没有规则及保存正文时采用选定工作区文本，always追加选定工作区文本；replace保留官方工具段/工具schema与独立运行时上下文，append保留原系统段。这是当前可复验的实现语义，不能把对旧源码歧义的选择标为旧桌面1:1通过，仍需产品侧确认该差异。
